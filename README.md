## 운영 방법

1. `data/disaster_map_data.xlsx` 파일의 재해별 시트를 수정합니다.
2. 같은 파일명으로 GitHub의 `data/disaster_map_data.xlsx`를 교체합니다.
3. Render가 자동 재배포합니다.
4. 화면의 재해 선택 드롭다운에서 폭염/호우/태풍/산불/대설/지진을 전환합니다.

## Excel 구조

- 01_재해설정: 지도단위, 기본 원형지표, 단위, 보조지표 정의
- 각 재해 시트:
  - B3:B10 공통 메타데이터
  - A13:I15 구호현황
  - 18행부터 피해현황
- 위도/경도를 직접 넣으면 해당 좌표를 최우선 사용합니다.
- 위도/경도가 비어 있으면 app.js 내부의 대표좌표 사전을 사용합니다.

## 주의

현재 폭염 시트의 '전남광주'는 원자료가 통합 표기이므로 지도에서 하나의 통합 지점으로 표시합니다.
실제 운영에서 광주광역시와 전라남도를 각각 표현하려면 원자료 자체가 분리되어야 합니다.
